ខ្មែរ Khmer admin

A local database for the language data of the Khmer autocomplete keyboard. Everything stays on this computer.

Consonant & vowel mapping

How Khmer letters and vowel signs are written in Latin letters: series, onsets, finals, vowel readings. The engine spells Khmer words and guesses Khmer spellings from these tables. Try a change live before you save it.

Dictionary

The Khmer words with their Khmerlish spellings (lexicon) and English translations. Search, edit, add words, and try what a typed word converts to.

Files

The engine reads data/mapping.json, lexicon.json, english.json and data.json. Export writes them from the database; then rebuild what uses them:

cargo run --release -p khcore --bin khbuild -- data/data.json data/lexicon.json khdata.bin data/english.json data/mapping.json
python3 web/build_demo.py data/data.json
Download mapping.json lexicon.json english.json

After exporting changed data, regenerate the golden test vectors (node tests/golden/gen.mjs): they are made from data/.
