The engine builds its Khmer → Latin spellings and its Latin → Khmer rule guesses from these tables. Save stores them in the database; Export writes data/mapping.json, which khbuild, the demo page and the apps read (see admin/README.md).

Consonants

Series: A = first series, O = second series (the same vowel sign sounds different after each). Onset: how the letter is written at the start of a syllable. Final: how it is written at the end of a syllable. ៉ / ៊: the letter can take muusikatoan (→ A series) / triisap (→ O series).

Vowels

Readings after a first-series (A) and a second-series (O) consonant, separated by spaces. The first reading is what the engine writes when it spells a Khmer word in Latin; the others are also understood when you type Latin. Lowercase a–z only. The sign can be a pair such as ាំ or ុះ; the first row (empty sign) is the inherent vowel.

Finals (Latin → Khmer)

What you may type at the end of a syllable, and the letters it can be. The engine's rule guesses use this. Add b → ប to make leab read as លាប.

LatinLetters

Extra onsets (Latin → Khmer)

Further ways to type the start of a syllable, on top of the onsets of the consonants above (for example g → គ, j → ចជ). An entry with the same Latin as a consonant's onset replaces it.
