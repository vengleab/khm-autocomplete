Khmer word dictionary

Each Khmer word has Khmerlish spellings (the lexicon: how people type it in Latin letters, separated by spaces) and an English translation (comma separated; typing one of them in the Khmer state converts to the word). The suggested spelling is made from the mapping. Press Export to write data/lexicon.json, english.json and data.json for the engine.
